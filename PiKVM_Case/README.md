# PiKVM Case

FreeCAD model. Work in progress.

Casing for [PiKVM v1](https://pikvm.org/) based on top of Raspberry Pi 3B with Pico H.

Uses [C790](https://wiki.blicube.com/blikvm/en/hdmi-csi-i2s/) HDMI to CSI converter based on [Toshiba TC358743XBG](https://toshiba.semicon-storage.com/eu/semiconductor/product/interface-bridge-ics-for-mobile-peripheral-devices/hdmir-interface-bridge-ics/detail.TC358743XBG.html).
