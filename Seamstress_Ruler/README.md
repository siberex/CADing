# Seamstress Ruler

Four-sided seam guide (sewing gauge) for quilting/sewing.

Fully customizable.
 
Text labels will be automatically updated upon configuration change.


# Recommended parameters

Recommended material: PETG or PLA.

Transparent PETG for base with black PETG for letters are optimal.

Recommended `letter_height` parameter is 0.2 for 0.2mm nozzle (1 × nozzle size).


# Prerequisites

```bash
cd ~/Documents/OpenSCAD/libraries
git clone https://github.com/openscad/scad-utils.git
```
