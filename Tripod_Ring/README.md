# Tripod Ring Attachment

Fixture to attach to the camera tripods with 1/4" mounts underneath main column.

My mini-tripod have this attachment hole and I want to make a ring to attach a heavy steel carabiner to it, to increase tripod stability.

Also useful to hang tripod for storage or whatever.

# Recommended parameters

Materials:

Hook: PLA

Ring: PLA or PETG

Recommended nozzle size: 0.1mm

0.2mm will work too, threading is perfectly usable at 0.2mm resolution.


# Prerequisites
